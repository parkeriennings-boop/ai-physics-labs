# 🧪 AI Physics Labs

A collection of interactive, browser-based physics sandboxes, neural network simulations, and engineering games built purely in standalone HTML/JavaScript. 

Playable directly in the browser via **GitHub Pages** with zero installation or dependencies required.

---

## 🎮 Interactive Labs & Simulations

Launch the main hub via **[index.html](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/index.html)** or jump directly into any of the individual experiments:

### 🤖 AI, Neural Networks & Evolution
* **[AntLab](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/antlab.html)** (`antlab.html`) — Pheromone colony and neural swarm physics simulation.
* **[DumbBot Academy](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/dumbbot-academy.html)** (`dumbbot-academy.html`) — AI training arena (*RoboRage*) featuring a 2,000-ghost Deep MLP, time-scaling controls (`0.01x` to `1000x`), and evolutionary learning.
* **[FlyBrain 3D](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/flybrain-3d.html)** (`flybrain-3d.html`) — Interactive 3D neural/brain simulation and visualization.
* **[WalkerLab 2D](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/walkerlab-2d.html)** (`walkerlab-2d.html`) — 2D bipedal/multi-legged locomotion and physics balance trainer.

### ⚙️ Engineering & Mechanics Sandboxes
* **[GearLab](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/gearlab.html)** (`gearlab.html`) — True rigid-body gear tooth, chain, and belt physics sandbox.
* **[GliderLab](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/gliderlab.html)** (`gliderlab.html`) — Aerodynamics and aircraft construction sandbox featuring 150 modular parts and high-speed physics simulation.
* **[OrbitLab](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/orbitlab.html)** (`orbitlab.html`) — Orbital mechanics and rocket flight simulator with 36 categorized rocket presets.

### 🏎️ Arcade & Physics Games
* **[BotBrawl](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/botbrawl.html)** (`botbrawl.html`) — Physics-driven robot combat arena.
* **[Containment Breach](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/containment-breach.html)** (`containment-breach.html`) — Zombie survival and fort-building physics sandbox.
* **[DriftLab](https://github.com/parkeriennings-boop/ai-physics-labs/blob/main/driftlab.html)** (`driftlab.html`) — 2D vehicle dynamics and drifting physics sandbox.

---

## ✨ Features

* **Zero Dependencies:** Each lab is self-contained in a single `.html` file using vanilla HTML5 Canvas, WebGL/3D, and JavaScript.
* **Built-in Tutorials:** Interactive onboarding guides across the simulations to help you get started quickly.
* **Mobile & Desktop Friendly:** Responsive controls designed to work across both desktop browsers and mobile touchscreens.
* **Live Deployment:** Automatically hosted and updated via **GitHub Pages**.
